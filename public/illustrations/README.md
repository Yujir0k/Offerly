# Иллюстрации Офферли

12 оригинальных прозрачных WebP созданы встроенным OpenAI image generation и сохранены в этой папке. Палитра: #402FFF, #EC1D35, белый/серый, светлая лаванда и графит.

- `auth-registration.webp`, `auth-registration-employer.webp` — регистрация кандидата и работодателя.
- `auth-login.webp`, `auth-login-employer.webp` — вход кандидата и работодателя.
- `auth-email.webp` — ожидание письма кандидатом.
- `auth-email-candidate-error.webp`, `auth-email-candidate-expired.webp`, `auth-email-candidate-success.webp` — остальные состояния кандидата.
- `auth-email-employer-waiting.webp`, `auth-email-employer-error.webp`, `auth-email-employer-expired.webp`, `auth-email-employer-success.webp` — четыре состояния работодателя.

Точные промпты: [первые три изображения](prompts.json), [остальные девять](extra-prompts.json). PNG-оригиналы в generated_images оставлены на месте. Для сайта использованы WebP с сохранённой прозрачностью.
