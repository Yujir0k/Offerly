# Вывод проверочных сценариев

Существовавшие JSON-отчёты перемещены сюда вместе с обновлением путей в генераторах и тестах. Их наличие не означает повторный прогон сегодня: проверяйте содержимое и соответствующий отчёт итерации. Зафиксированный последний прогон хранится отдельно в `../2026-10-10-final/`.

Здесь допустимы только обезличенные результаты. Токены, cookie, пароли, почтовые коды и пользовательские резюме хранить в приватном каталоге отдельной QA-среды.
