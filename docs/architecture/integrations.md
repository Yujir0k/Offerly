# Интеграции и границы MVP

## ФСП ID / Keycloak — клиент реализован, провайдер не подключён

Кнопки входа/регистрации и привязки с логотипом ФСП, четыре API ручки входа и две ручки истории, Authorization Code + PKCE, одноразовый state/browser binding, nonce и JWT/JWKS-проверки реализованы. Без настроек кнопка ничего не делает. Подробная схема, параметры, проверки и ограничения: [fsp-id.md](../guides/fsp-id.md).

`external_identities` связывает issuer+subject с user_id и согласованным participant_id. Автоматического объединения по email нет. Вход не добавляет достижения и грейд; реальный реестр достижений не подключён. Демонстрационный ID доступен только изолированному демо.

## ATS — концепция

Сначала входящие вакансии и обратные события application.created, invitation.responded, application.status.changed. Таблица mappings связывает external_system/external_id с внутренними company/job/application ID; OAuth/API-ключ хранится сервером. Webhook подпись+timestamp; дедупликация event ID; idempotency key для POST; outbox и retry с dead-letter; ограничение по компании. Историю и контакты передавать только в рамках согласия конкретной компании. Пока не реализованы webhook, mappings и очередь; подключение к конкретному ATS не заявляется.

## Почта

Коды подтверждения уже используют nodemailer SMTP, хеш, 10 минут, 5 попыток, ограничение отправки. SMTP-провайдер не настроен. Письма о приглашениях/статусах/подборках — будущая очередь outbox с учётом настроек, паузы, частоты и отказа от необязательных рассылок. Транзакционные письма безопасности не отключаются вместе с маркетинговыми.

## Общение и найм — реализовано

Межаккаунтный текстовый чат после принятия приглашения или добровольного отклика, история/пагинация, непрочитанные и защита replay. HTTP polling, серверные права участников; файлы и звонки не реализованы. Процессы найма, приватные заметки/напоминания, скрытые компании, сравнение, именные поиски с новыми совпадениями, встречи/ICS и регулярные задачи компании реализованы отдельно от профессионального грейда. [Сценарии, миграции, ограничения](../guides/mvp-features.md), [прежние проверки чата](../reports/2026-10-10/hiring-chat-20261010.md).

## Безопасность аккаунта и политика

Восстановление пароля кодом на почту реализовано; после сброса все сеансы отозваны. Транзакционные письма используют существующий local file/Mailpit/SMTP адаптер; внешний SMTP остаётся отложенным. [Версии согласий и сроки](data-policy.md), [концепция антифрода](anti-fraud.md).

Расширенный фиксированный демореестр (с историей/без истории), собственные ручки истории и границы настоящего подключения описаны в [fsp-id.md](../guides/fsp-id.md).
