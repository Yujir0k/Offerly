# Синтетический каталог специалистов

Набор `synthetic-specialists-1` содержит 720 разных профилей: по 60 на каждое из 12 профессиональных направлений, по 20 попыток на Junior, Middle и Senior. Дополнительно сохранены исходные шесть демонстрационных кандидатов и существующая история аккаунтов.

Из 720 завершённых попыток 662 подтвердили запрошенный уровень, 58 не подтвердили его. Это распределение программных сценариев, а не статистика реальных кандидатов. В наборе 16 городов; на каждом направлении есть Junior, Middle, Senior и разные стеки.

Каждый профиль имеет отдельное имя, стек, профессиональное описание, проект, город, формат работы, опыт, зарплатные ожидания и готовность к выходу. Люди с нулевым коммерческим опытом имеют учебный проект. Технологии из резюме остаются заявленными: испытание не доказывает отдельно владение каждой библиотекой.

## Откуда взяты результаты

`scripts/generate-synthetic-candidates.mjs` запускает неизменённый engine `formal-generator-7.3.3`: создаёт уникальную попытку, открывает свидетельства, отправляет ответы и исполняемые планы, проходит адаптивные уточнения до завершения. Программные респонденты имеют разные вероятности ошибок по четырём компетенциям. Длительность моделируется виртуальным временем в пределах ограничения движка.

Грейд появляется только при решении `CONFIRMED`. Неуспешная попытка оставляет заявленный уровень, без подтверждённого грейда. Индекс — исходная оценка движка, публичные компетенции — его собственная замороженная проекция. Числа и решение не подставляются вручную. Это программная симуляция, а не прохождение живыми людьми через браузер, и не доказательство точности оценки реальных специалистов.

Все исходные завершённые snapshots сохранены локально в `.data/synthetic-candidates/snapshots/*.json.gz`. SHA256 каждого снимка, число ответов и версия генератора связывают его с публичной записью. Публикуемый JSON не содержит ключи, рубрики, ответы и планы. Проверка сравнивает все 720 записей с их исходными снимками.

## Достижения и изоляция

У части профилей есть 1–3 вымышленных соревнования с дисциплиной, датой, результатом, личным/командным участием и релевантностью направлению. Эти сведения явно помечены `source: demo`; они не выдаются за настоящий реестр ФСП. ФСП ID начинается с `DEMO-`. Часть событий относится к другому направлению, чтобы показать изменение релевантности при выборе вакансии.

Адреса используют зарезервированный домен `example.test`, телефоны и внешние ссылки отсутствуют. Синтетические аккаунты не имеют пароля и не могут войти обычным способом. Профили добавляются только в приватные scope демонстрационных аккаунтов; обычный рынок и реальные пользователи не изменяются. В карточке видна метка «Демо-профиль · результат симуляции».

## Воспроизведение

Использовать существующие зависимости и npm lockfile. В текущем окружении pnpm по умолчанию инициирует автоустановку перед run/exec; не смешивать её с подготовленным npm node_modules.

1. `npm run assessment:build`.
2. `node_modules/.bin/tsx scripts/generate-synthetic-candidates.mjs` — генерация или восстановление из сохранённых локальных записей. Стандартный размер 720; не менять размер публикуемого набора.
3. Остановить dev-сервер и сохранить резервную копию `.data/postgres`.
4. `node_modules/.bin/tsx scripts/populate-synthetic-candidates.ts` — заполнить существующие приватные демо. Скрипт закрывает PGlite перед завершением.
5. `npm run dev`.

На Windows использовать `node_modules\.bin\tsx.cmd`. Для каждой новой демоверсии набор устанавливается автоматически в той же транзакции, что и базовые данные. Установка повторяема, не создаёт дублей и не перезаписывает изменения существующего профиля. Готовый публичный набор хранится в `data/synthetic-candidates-v1.json`; повторное дорогое прохождение при каждом входе не требуется.

Отчёт по направлениям и грейдам: `qa/results/latest/synthetic-candidates-results.json`. Проверки: `qa/synthetic-population.test.ts` и `qa/synthetic-catalog-check.mjs`.

Основной локальный каталог заполнен: в каждом из двух существующих приватных демо добавлены 720 профилей. Повторная установка добавила 0; существующие профили и обычные аккаунты сохранены. Резервная копия до установки: `.data/backups/before-synthetic-20261010`.

- 22 теста: 17 ранжирования, 3 набора/снимков/установки, 2 защиты контактов и дат. Все прошли; все 720 хешей и результатов совпали с неизменённым engine.
- 74 HTTP-проверки каталога: 12 направлений, 36 групп по грейду, результаты и даты, релевантность ФСП, технологии, сравнение, страницы и изоляция. Отчёт: `qa/results/latest/synthetic-catalog-results.json`.
- 63 проверки сценариев работодателя и 54 проверки общей платформы успешны. После исправления дат отдельно повторены 54 проверки доступа и контактов.
- TypeScript, production build и ESLint новых файлов и затронутых компонентов успешны. В существующем `lib/employer-profile.ts` остаются три прежних `no-explicit-any`; они присутствовали до этой задачи.
- В браузере проверены 726 результатов, 60 специалистов GenAI, новые направления фильтра, карточка с четырьмя компетенциями, даты и демо-соревнования. Основной сервер снова работает на `http://localhost:5173`.

Неподтверждённый уровень больше не объясняется утверждением, что испытание не завершено: среди профилей есть завершённые неуспешные попытки.
