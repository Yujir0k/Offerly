# Даты опыта и переходы авторизации — 10.10.2026

## Поведение

- Общий MonthPicker для регистрации и профиля ограничен текущим месяцем в Europe/Moscow. Будущие годы отсутствуют в списке, ручной ввод 2100 ограничивается текущим годом, будущие месяцы отключены. Граница обновляется при открытии календаря и раз в минуту. Окончание не может быть раньше начала.
- lib/work-dates.ts используется клиентом и сервером. Оба действия profile / profile-draft отклоняют будущие начало и окончание, неверный формат и обратный диапазон до изменения профиля. Незавершённый черновик может содержать пустые даты.
- Автоматическое приветствие после регистрации показывает логотип 176px, полностью проигрывает вступление 2,6с, сохраняет состояние и плавно открывает профиль кандидата / компанию работодателя. Убрана прежняя задержка 700мс, обрывавшая анимацию, и уменьшенный промежуточный логотип 64px. Под приветствием готовится целевой раздел вместо обзора. Автоматический сценарий не требует кнопки «Далее». Ручное повторное приветствие из помощи сохраняет кнопку.
- Вход по паролю с подтверждённой почтой использует отдельный непрозрачный экран с логотипом 176px: кабинет монтируется под ним, затем открывается за 550мс после полной сборки логотипа. Ответ авторизации используется сразу; повторный запрос состояния при первом открытии кабинета не нужен. Периодическое обновление кабинета сохранено. Повторная email-проверка не добавлена.
- Учитывается prefers-reduced-motion. Ошибки входа остаются на форме; экран перехода начинается только при успешном входе с подтверждённой почтой.
