# Реализация расширения MVP — 10.10.2026

Утверждено пользователем: закрыть пробелы аудита ТЗ (кроме материалов сдачи), реализовать предложенные конкурентные функции. Ветка feature/complete-mvp-hiring, существующие незакоммиченные изменения сохраняются.

- [x] Единые 12 специализаций, поиск по указанным/подтверждённым технологиям, рекомендации категории.
- [x] История опросов, общая OpenAPI, актуальные инструкции.
- [x] Скрытые компании: каталог/прямой доступ/приглашения/экспорт/сравнение.
- [x] Сравнение 2–3 кандидатов, фиксированные этапы по процессу, приватные заметки, напоминания.
- [x] Именованные поиски обеих ролей и новые совпадения внутри приложения.
- [x] Необязательная причина отказа, встречи со слотами/переносом/отменой/ICS.
- [x] Регулярные задачи компаний и честная отдельная история без подмены грейда.
- [x] Восстановление пароля с одноразовым кодом и отзывом сеансов.
- [x] Концепция антифрода, версии согласия и политика хранения.
- [x] Целевые проверки, авторский фиксированный набор подбора, отчёт ограничений.

Вне объёма: SMTP-провайдер, публикация/домен/GitHub, материалы защиты, админка, 90-дневный лимит. Реальные настройки ФСП и внешний человеческий пилот требуют внешних данных/участников; не имитировать их завершение.

Проверки и ограничения: [mvp-verification.md](mvp-verification.md). Внешняя независимая разметка и человеческий пилот не выполнены; синтетический набор их не заменяет.
