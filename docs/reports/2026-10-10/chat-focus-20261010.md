# Переписка и навигация — 10.10.2026

## Поведение

- Соискатель: Обзор → Опрос → Проверка навыков → Результаты → Вакансии → Приглашения → Сообщения → Мой профиль.
- Работодатель: Обзор → Поиск кандидатов → Подборки → Приглашения → Сообщения → Вакансии → Моя компания.
- «Мои процессы», «Этапы найма», кнопка добавления в процесс и polling напоминаний убраны. Старый URL `/demo/:role/hiring` ведёт в сообщения. Существующие серверные записи, API и история сохранены; это отложенные возможности, не текущий интерфейс.
- У работодателя фильтры приглашений только Все / Принятые / Отклонённые. Остальные ожидают ответа. Есть поиск по роли, имени/номеру кандидата и навыкам; счётчик непрочитанных приглашений остаётся только у получателя.
- При принятии приглашения либо добровольном отклике разговор создаётся в одной транзакции с сохранением согласия. Уникальность company+candidate исключает повторные диалоги. UI открывает переписку автоматически; повторное открытие через ChatLaunch сохраняется.
- В чате постоянная отметка об обмене контактами, имя работодателя и компании, фотография кандидата/логотип компании при наличии; у работодателя подтверждённый грейд из серверного профиля. При отсутствии изображения используются инициалы. Приватные ключи файлов не выдаются; endpoint фотографии проверяет доступ к разговору.
- Фото: GET `/api/conversations/:id/avatar?role=candidate|employer`. Авторизация и роль проверяются на сервере независимо от query.
- Подсказки всех доступных разделов включают Сообщения. «ОК» запоминает прочтение одного раздела. «Не показывать больше» — фиолетовая кнопка, отключающая автоматические подсказки для аккаунта в обоих кабинетах. Сохранение на сервере в `settings:tour_preferences_v1`, без новой схемы. «Помощь» позволяет вручную открыть одну подсказку либо снова включить знакомство. Настройка не переносится на другой аккаунт.

## Миграция и запуск

012_contact_conversations.sql добавляет разговоры для ранее принятых приглашений и откликов, сохраняя существующие ID, сообщения и прочтения. Исключены собственные/удалённые аккаунты и разные scope. Миграция идемпотентна. PGlite применяет при запуске; PostgreSQL — штатный `npm run db:migrate` перед обновлением. Новых зависимостей и переменных окружения нет. Основной сервер: http://localhost:5173; локальная почта: http://localhost:8025. Порт5188 — прежняя экспортная копия, её исходники этой правкой не обновлялись.
