# Проверка Офферли после переноса на VPS — 11 октября 2026

Основные пользовательские сценарии прошли на работающей production-сборке Aeza. Проверка выполнена самостоятельно, без демонстрации и без редактирования исходных пользовательских профилей. Изменения продуктового кода по итогам этого прогона не понадобились.

Это проверка приложения через закрытый SSH-туннель к VPS. Публичный домен и реальная доставка почты пока не готовы; результат не означает завершённый публичный запуск.

Email тестовых пользователей подтверждался отдельной служебной фикстурой, доступной только через SSH. Это подготовка тестовых данных, **не проверка доставки письма**. Тестового HTTP-маршрута в production нет; служебные файлы после проверки убраны из контейнера.

В матрице профессиональных испытаний использованы синтетические ответы по приватному эталону. Тайм-аут испытания ускорялся установкой дедлайна только собственной тестовой попытки. Это проверка поведения, а не экспертная оценка качества найма на людях.

## Сохранность и эксплуатация

- Приложение перезапущено без сброса PostgreSQL и тома загрузок. Старые сессии сохранились; хеши профилей, компаний, подборок, результатов, переписки, задач и исходного PDF до/после совпали. Ключ шифрования MCP сохранился.
- Контрольные хеши существующих профилей, компаний, вакансий, подборок, приглашений и сообщений совпали. Одноразовые аккаунты отдельно учитывались при проверке удаления.
- 120 запросов чтения с параллелизмом 6: ошибок нет, медиана 166 мс, p95 670 мс, максимум 967 мс через SSH-туннель. Это ограниченная проверка устойчивости, не оценка предельной нагрузки или публичной задержки.
- Новый `pg_dump` восстановлен в отдельную `offerly_restore_final_20261011`, рабочая БД не заменялась. Сверены все 40 таблиц: 39 совпали по содержимому; `auth_throttles` отличается ожидаемым изменением счётчиков запросов после снимка.
- Копия базы и архив загрузок сохранены на VPS и вне VPS в приватном локальном каталоге резервных копий; SHA256 совпали. Первоначальный перенос дополнительно сверял 38 таблиц/4416 строк и 238 файлов с оригиналами.
- После проверок 25 созданных нами тестовых профилей скрыты из поиска, две тестовые вакансии архивированы, тестовый ключ MCP отозван. Аккаунты и доказательства сохранены приватно.
- 436 файлов продуктовых исходников на VPS побайтно совпали с активной копией; генерируемый `dist` исключён. Предпросмотры PDF и первоначальный архив вынесены из каталога релиза в приватный архив; файлы приложения не подменялись.

## Что ещё требует завершения

1. **Домен и HTTPS.** На последней проверке авторитетный DNS Рег.ру отдаёт `193.233.220.30`, публичный Cloudflare отвечает NXDOMAIN. Caddy работает и настроен на домен, но действующий публичный сертификат ещё не подтверждён. Проверку публичного адреса, редиректов и сертификата нужно завершить после обновления делегирования.
2. **Почта.** SMTP не настроен; соединение VPS с `postbox.cloud.yandex.net:465` завершилось тайм-аутом. Нужны подтверждение домена Postbox, ключ доступа, настройка отправителя и доступность порта. После этого обязательны настоящие подтверждение email, восстановление пароля и смена почты. Фоновые email-уведомления о приглашениях/подборках ещё не реализованы.
3. **ФСП.** Production-провайдер и реестр не подключены. На VPS корректно показана недоступность; локальный OIDC-контур ранее прошёл 80 проверок, что не означает подключения настоящей ФСП.
4. **Дополнительный функционал ТЗ.** Автоматические периодические короткие задания и отдельные испытания технологий в текущем UI не завершены. Добровольные задачи в чате и профессиональные грейды работают. Отдельный дублирующий опрос ранее снят по решению пользователя; OCR сканов не реализован.
5. **Сопровождение и сдача.** Автоматическое расписание внешних резервных копий ещё не настроено. Исходный Git checkout `offerly-web/` пока не синхронизирован с действующей копией; GitHub не обновлялся. Остаются актуальный комплект сдачи и экспертная проверка на людях.

Полная прежняя сверка с ТЗ и согласованные отличия: [локальный отчёт](../2026-10-10/current-verification.md). Исходное ТЗ не изменялось.
