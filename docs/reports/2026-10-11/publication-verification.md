## Изменения

Таймер браузера использует единый подписываемый источник. Смена роли, открытие окон и восстановление форм больше не требуют синхронного изменения состояния в эффектах. Удалён неиспользуемый старый интерфейс этапов найма; серверные интеграции и действующие страницы сохранены. Правила lint собственного приложения не отключались.

## Публикация и эксплуатация

Перед пушем проверены подготовленные файлы: SMTP-пароль, приватные SSH/API-ключи и личный тестовый адрес не обнаружены. В Git не входят env, рабочие базы, uploads, дампы и кеши. README содержит локальный Node/Docker-запуск, архитектуру, стек, синтетические скриншоты и место для видео.

SMTP.BZ обнаружил DNS-записи, домен ожидает модерации. Приватный файл с учётными данными сохранён вне проекта с правами 600. Проверки соединения на 465, 587 и 2525 с локальной машины завершились тайм-аутом до SMTP-авторизации; тестовые письма в этой итерации не отправлялись; отправка через нового провайдера с VPS ещё не подтверждена. Универсального получателя нет: письмо адресуется аккаунту или соответствующему этапу смены адреса.

Остаются эксплуатационные действия: восстановить административное SSH-соединение, выложить эту итерацию на VPS и проверить последовательный перезапуск, удалить отдельный restore-контейнер, применить обновления безопасности ОС с контролируемым перезапуском. По снимку консоли было 215 ожидающих обновлений безопасности; отсутствие доступа не позволяет заявить их установку. Восстановление резервной копии проверено, но регулярные внешние копии и оповещения мониторинга ещё не настроены. Нужен длительный смешанный прогон именно на VPS после выкладки. Реальная ФСП требует контракта организатора; человеческий пилот качества испытаний остаётся отдельным этапом.
