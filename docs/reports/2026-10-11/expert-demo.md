# Экспертная демонстрация и навигация — 11.10.2026

При первом открытии страницы «Проверка уровня» поверх обычной страницы появляется большое окно знакомства: специализация, грейд, правила демонстрации. Демонстрация запускается в текущем аккаунте, в отдельном режиме `presentation=expert`. Окно можно закрыть; повторно оно доступно кнопкой «Открыть демонстрацию». Кнопка «Заполнить правильный ответ» подготавливает текущий шаг, включая план выполнения и источники. Она не отправляет ответ: эксперт сохраняет его обычной кнопкой и видит переход к следующему заданию. Таймер демонстрации не истекает по настенным часам. Отчёт явно подписан демонстрационным, показывает подтверждение или неподтверждение выбранного грейда в рамках демо и сохраняется в разделе «Результаты». Реальный грейд, профильная квалификация, подбор и интервалы настоящих проверок не меняются.

Сервер проверяет аутентификацию и подтверждение почты (либо серверную демоидентичность), роль кандидата, Origin, владельца, текущий шаг и ревизию. Демо хранится в отдельном scope и коллекции `expert-sessions`; обычный API не видит такие попытки. Заполнение доступно только для собственных демонстрационных попыток, в том числе в обычном подтверждённом аккаунте. Операция заполнения через настоящий API испытаний запрещена. Правильные ответы и рубрики настоящих испытаний в клиент не передаются. Реальная активная попытка и ограничения повторов остаются независимыми. Миграция 025 добавляет отдельную коллекцию и индекс, не меняя прежний индекс настоящих попыток; ожидание блокировки ограничено двумя секундами.

`qa/expert-demo.test.ts`: 36 сочетаний / 397 шагов через настоящий серверный сервис и изолированную PGlite. Все демо дошли до CONFIRMED; проверены чужой владелец, обычная идентичность, неправильный шаг, устаревшая ревизия, повторная демонстрация, возобновление спустя три дня, отсутствие рубрик в обычном ответе. Настоящая активная попытка сохранилась, профиль и таблица результатов не изменились. Браузер: полный проход 11 оставшихся шагов текущей демопопытки, заполнение видимых контролов, отчёт, без JS-исключений. Ролик v2 показывает отдельную запись обычных ответов, без экспертного заполнения.

Публичное меню теперь разрешает авторизацию до показа кабинета. Посетитель без входа попадает сразу на регистрацию с выбранной ролью и сохранённым назначением. Промежуточный брендовый загрузчик не монтируется. Логотип убран из перекрывающих переходов; вход не удерживается искусственно 2,4 секунды. Ссылки разделов лендинга прокручивают за 280 мс с плавным торможением; reduced-motion учитывается.

В локальном запуске миграции теперь записываются в schema_migrations и выполняются транзакционно один раз. Это предотвращает повторное применение старого ограничения коллекций поверх уже созданных демопопыток. Production по-прежнему применяет миграции отдельной задачей релиза.

## Уточнение: свободная навигация и отчёты в текущем аккаунте

Все уже выданные вопросы доступны в любом порядке; дополнительные адаптивные задания появляются только после обязательной части. Изменение ответа снимает только выбранный ответ, без удаления поздних ответов, открытых источников или черновиков. Алгоритм перехода выбирает следующий несохранённый шаг; формулы, рубрики, пороги и условия итогового решения сохранены. При чтении незавершённой старой попытки поздние ответы, снятые прежней каскадной политикой и сохранившиеся в журнале изменений, возвращаются однократно, без перезаписи новых ответов и без восстановления самого редактируемого ответа. Завершённые отчёты не переоцениваются.
