# Локальная почта Mailpit

Mailpit принимает SMTP-письма приложения и показывает их в локальном браузере. Внешний почтовый аккаунт не нужен; письма не отправляются адресатам в интернете.

На macOS: `brew install mailpit`. В каталоге приложения запустите `npm run dev:mail`. Оставьте процесс работать и откройте http://localhost:8025. Отдельно запустите `npm run dev`.

Добавьте параметры из `.env.mailpit.example` в `.env.local`, сохранив остальные настройки, и перезапустите приложение. SMTP слушает только 127.0.0.1:1025, интерфейс — 127.0.0.1:8025. Хранилище `.data/mailpit` приватное и не входит в репозиторий. Пересылка/relay не включены.

После регистрации нажмите «Отправить код». Письмо появится в Mailpit; введите шесть цифр на сайте. Действуют настоящие проверки: 10 минут, одноразовость, ограничение отправки и попыток. В демонстрационном аккаунте используется отдельная явная имитация; она не подтверждает настоящую почту.

Подтверждённые аккаунты входят с паролем без повторного кода. При смене адреса в настройках сначала проверяется код текущей подтверждённой почты либо пароль аккаунта, затем код новой почты. Адрес изменяется только после второго этапа; остальные сессии отзываются. Поток привязан к текущей сессии и ограничен 30 минутами. Коды различных назначений невзаимозаменяемы.

`MAIL_TRANSPORT=mailpit` разрешён только в разработке с loopback SMTP. Для сервера используйте настоящий SMTP с TLS; Mailpit не служит production-рассылкой. Резервный `MAIL_TRANSPORT=file` сохраняет приватные письма без SMTP. Опциональный `MAIL_PREVIEW=true` показывает такой тестовый код только в development.

HTTP-регрессия двух ролей: на отдельной базе/сервере 5174 с Mailpit выполните `node qa/email-change-check.mjs`. Не запускайте QA на пользовательских данных.

Официальная документация: https://mailpit.axllent.org/docs/install/ и https://mailpit.axllent.org/docs/configuration/smtp/.
