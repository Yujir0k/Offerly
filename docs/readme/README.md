# Материалы README

`media/offerly-preview-60s.mp4` — исходный ролик, предоставленный автором проекта, 60 секунд, 1920×1080. `media/offerly-preview-60s.gif` — его полная анимационная версия для автоматического показа в README без звука, 720×405, 6 кадров/с, бесконечный цикл. Время ролика не сокращено. Нажатие на анимацию открывает исходный MP4.

GitHub позволяет читателю отключить автоматическое воспроизведение GIF в настройках доступности; README не переопределяет этот выбор. [Настройки GitHub](https://docs.github.com/en/account-and-profile/how-tos/account-settings/managing-accessibility-settings).

`screenshots/` — 20 снимков демонстрационных кабинетов в компьютерной версии. Показанные контакты и компании — демо-данные. Снимки экспертного испытания иллюстрируют методику, не реальную квалификацию пользователя.

`offerly-documentation.pdf` и `offerly-documentation.md` — согласованная сопроводительная документация. `research/` — оригинальные статьи и их атрибуция.

Места для будущих ссылок на демо и презентацию находятся в начале корневого README. После получения URL замените строку «ссылка будет добавлена» настоящими Markdown-ссылками.
