# Материалы README

`media/offerly-preview-60s.mp4` — исходный ролик, предоставленный автором проекта, 60 секунд, 1920×1080. `media/offerly-preview-60s.webp` — его полная анимационная версия для автоматического показа в README без звука, 720×405, 25 кадров/с, бесконечный цикл. Время ролика не сокращено. Нажатие на анимацию открывает исходный MP4.

`screenshots/` — 20 снимков демонстрационных кабинетов в компьютерной версии. Показанные контакты и компании — демо-данные. Снимки экспертного испытания иллюстрируют методику, не реальную квалификацию пользователя.

Короткие анимации показывают действия в локальной демоверсии на демонстрационных данных:

- `media/resume-pdf-import-desktop.gif` — загрузка PDF, проверка и выбор найденных полей, перенос данных и сохранение профиля.
- `media/assessment-walkthrough-desktop.gif` — этапы проверки: сценарий, выбор ответа, инцидент, источники, анализ решения и отчёт. Снята экспертная демонстрация с заполнением эталонных ответов; настоящий грейд не меняется.
- `media/employer-search-desktop.gif` — поиск, выбор двух кандидатов, сравнение параметров и различий, просмотр профиля и заполнение предложения. Приглашение не отправлялось.

Каждая анимация длится около 7 секунд и смонтирована из снимков интерфейса компьютерной версии с окном 1440×900, без обрезки бокового меню. Размер GIF — 1280×840 с подписями этапов, частота переходов — 25 кадров/с; цикл повторяется без звука.

`offerly-documentation.pdf` и `offerly-documentation.md` — согласованная сопроводительная документация. `research/` — оригинальные статьи и их атрибуция.

Места для будущих ссылок на демо и презентацию находятся в начале корневого README. После получения URL замените строку «ссылка будет добавлена» настоящими Markdown-ссылками.
