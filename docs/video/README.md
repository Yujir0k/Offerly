# Видео и демонстрация

Готов рекламный motion preview v2: 60 секунд, 1920×1080, 30 кадров/с, H.264 / AAC. Показаны регистрация, профиль, вакансии, обычное решение инженерного вопроса, выбор и сравнение кандидатов, приглашение и чат. Ответы выбираются обычными контролами с паузами и сохраняются, без экспертного автозаполнения. Профили синтетические. Музыка написана для ролика без внешних треков и семплов.

[Промпт и режиссёрский бриф](preview/BRIEF.md) · [Монтажная HTML-сцена](preview/index.html) · [Музыка](preview/music.py) · [Потоковый рендер](preview/render.mjs) · [Обычное прохождение вопроса](preview/assets/assessment.mp4).

[Готовый offerly-preview-60s.mp4](offerly-preview-60s.mp4) включён в репозиторий и передан отдельным артефактом. Для повторного рендера установите FFmpeg, Node.js и Playwright (с Chromium), затем из корня репозитория:

```sh
node docs/video/preview/render.mjs /path/to/offerly-preview-60s.mp4
```

При внешней установке Playwright задайте `PLAYWRIGHT_MODULE` (путь к `playwright/index.mjs`); для установленного Chrome — `CHROME_PATH`. Рендер пишет кадры прямо в FFmpeg, без каталога из тысяч картинок. Готовая дорожка `score.m4a` уже включена. Пересоздать её можно через `music.py` (Python + NumPy) и AAC-кодирование FFmpeg. Шрифты распространяются по OFL; тексты лицензий рядом с файлами.

## Экспертам и для записи экрана

На сайте: «Войти» → «Посмотреть демоверсию» → «Проверка уровня» → «Открыть демонстрацию». Выберите специализацию и грейд, начните проверку. На каждом шаге нажмите «Заполнить правильный ответ», затем обычную кнопку сохранения/продолжения. Можно повторять без ожидания; демонстрационный отчёт не меняет квалификацию профиля. [Устройство и проверки изоляции](../reports/2026-10-11/expert-demo.md).

Для отдельного подробного скринкаста: профиль вручную/PDF → подтверждение почты → испытание → категория → поиск работодателя → приглашение с зарплатой → согласие → чат → добровольная задача → сохранение ответа → завершение по сроку.

Используйте синтетические аккаунты; не показывайте пароли, коды, приватные адреса и персональные файлы.
