# Скринкаст

Место для будущей записи: `offerly-demo.mp4` или ссылка на видео в основном README.

Сценарий: профиль вручную/PDF → подтверждение почты → испытание → категория → поиск работодателя → приглашение с зарплатой → согласие → чат → добровольная задача → сохранение ответа → завершение по сроку.

Используйте синтетические аккаунты; не показывайте пароли, коды, приватные адреса и персональные файлы.
